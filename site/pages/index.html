Security testing that waits for your authorization.

secskills is one binary that maps a target's attack surface, runs OWASP-mapped tests, and writes the report, for a source repository, a sandboxed build, or a live domain. It will not send a packet to a target until you confirm you are allowed to test it.

go install github.com/gleicon/secskills/cmd/secskills@latest

Or download a static binary for Linux, macOS, or Windows. Install options

Three ways in

You haveCommandTouches a target?
A source repositorysecskills source ./repoNo. Static review with embedded ast-grep rules.
A buildable artifactsecskills sandbox ./ctx --confirmOnly its own Docker container.
A live app or domainsecskills discover then testYes, behind the authorization gate.
A network block you ownsecskills discover --cidr …Yes, per IP, gated and rate-limited.

An engagement, start to finish

  1. Research without touching the target

    secskills profile example.com --output ENGAGEMENT-profile.md

    Passive OSINT: subdomains, edge and CDN, ASN. No traffic to the target.

  2. Write down what you are allowed to test

    secskills scope --init        # then edit .secskills-scope.yml
secskills scope --validate

    Targets, exclusions, expiry, and who confirmed it. The gate honors this file.

  3. Map the attack surface

    secskills discover example.com

  4. Test it

    secskills test example.com --deep

    Headers, TLS, exposures, component CVEs, and technology-specific checks. Non-destructive by default.

  5. Report

    secskills report --pdf example.com --output example.pdf

    Markdown, HTML, or PDF, mapped to OWASP, CWE, SOC 2, ISO 27001, and PCI-DSS.

What you get

  • Findings you can defend. Each one carries its evidence, a reproduction command, a validation state, and an OWASP/CWE mapping. Severity follows a written rubric, not just CVSS.
  • Retests that answer “is it fixed?” report --retest re-probes every finding and marks it fixed, still present, or regressed.
  • Output your tools already read. SARIF 2.1.0, CycloneDX 1.5 with VEX, and CSV/JSON ticket rows.
  • Signed runs. Run metadata and the evidence chain are signed with ed25519 and verifiable later.
  • Offline knowledge. The OWASP cheat sheets and per-stack fix recipes ship inside the binary.
  • Graceful degradation. Around 60 external tools widen coverage when present. secskills doctor tells you what is missing and how to install it; nothing is required.
