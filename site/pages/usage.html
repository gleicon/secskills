Using secskills

Every command is one reproducible step. Run secskills help for the list and secskills <command> -h for its flags. This page explains the ideas the commands share, then lists them by job.

Concepts

Authorization gate
Commands that send traffic to a target refuse to run until you pass --confirm or keep an authorized, unexpired scope file that lists the target. See Safety.
Scope file
.secskills-scope.yml in the working directory (or the path in SECSKILLS_SCOPE). It records the engagement, who confirmed it, targets, exclusions, expiry, and whether intrusive tests are allowed. Write it with secskills scope --init or the /secskills-intake skill.
Profile
How far test may go. Each level includes the one before it.
Workdir
Per-target scratch space for discovery output, evidence, and logs: $SECSKILLS_WORKDIR, or secskills/<target> under your user cache directory (~/.cache on Linux, ~/Library/Caches on macOS). Created readable by you only; a symlinked or foreign-owned workdir is refused.
Findings store
Saved runs per target in ~/.secskills-findings/<target>/. Reports, tickets, exports, and retests read from it. Treat it like a credentials store.

Test profiles

ProfileAdds
passiveOSINT only, no target traffic beyond discovery.
safe-active (default)Header, TLS, and exposure checks.
adversarial-readonlyBypass variants, safe exploit primitives, OAST callbacks, stateful pivots. Still read-only.
authorized-exploitCredentialed and state-changing tests. Needs --intrusive and --intrusive-confirm.

Assess a target

CommandDoes
profile <domain>Passive OSINT brief: subdomains, edge and CDN, Shodan data when a key is set. No target traffic.
scope --init / --validateWrite the scope template, or show what the current file authorizes.
discover <domain>Subdomains, resolution, live hosts. Writes live_hosts.json to the workdir.
test <target>OWASP Top 10 checks against the surface. --deep adds nuclei, sslscan, content discovery, and screenshots.
source <path>Static review with the embedded ast-grep rules. No network, no gate.
sandbox <ctx>Build and run an artifact in Docker, then test only that container.
graph <seed…>Related domains from certificates, CNAMEs, and shared infrastructure. They are listed with their authorization status and never tested.
watch <target> --interval 6hRe-assess on a schedule and report new, fixed, and regressed findings.
integrity snapshot|verify <url>Record a response hash, then detect later rewriting by an intermediary.

Useful test flags

FlagUse
--profileOne of the profiles above.
--auth-token, --cookie, --auth-headerTest the authenticated surface. Without them, authenticated checks are reported as not available.
--auth-token-b, --cookie-bA second identity for the access-control (BOLA/IDOR) differential.
--insecure-authSend credentials to a host with an untrusted certificate. Off by default; only for self-signed targets you accept.
--intrusive + --intrusive-confirmAllow write and credential tests. Both are required.

Findings and reports

CommandDoes
report --render <target>Full Markdown report.
report --html|--pdf <target> --output fFormatted report. PDF needs Chrome or Chromium.
report --audit <target>Short auditor report: control objectives, test ledger, attestation.
report --retest <target>Re-probe every finding: fixed, still present, or regressed.
report --lint <target>Check the report's invariants before you send it.
tickets <target>One row per finding, CSV or JSON, with severity, SLA, priority, owner, and business risk.
export --format sarif|cyclonedx <target>SARIF 2.1.0, or CycloneDX 1.5 with VEX.
findings list|show <target>Inspect stored runs.
override --target … --key … --severity … --reason …Record a reviewed severity change. The automated value is kept beside it.
attest --sign|--verify <target>Sign a run with your ed25519 key, or verify a signed run.

Network blocks

For an ASN or CIDR you are authorized to assess. The capture stages touch the network; the rest run offline over the workdir. Full recipe

CommandDoes
discover --cidr … / --asn …Sweep into observations.jsonl. Blocks wider than /20 need --allow-large.
enrich, leakcheck, kprobeVersions and CPEs; exposed files and open datastores; single-packet kernel-path probes.
dbcheckOpen or vendor-default-credential datastores. Needs --confirm and --intrusive-confirm.
feed kev|epss|nvdCache vulnerability intelligence. No target traffic.
cvematch, lifecycle, prefix-reportRank CVE candidates, track their state, write the block report.
plan, tokenSplit a block across workers; sign their scope.
precision, deliver, notify, fleetPrecision gate, per-tenant feeds, alert latency, anonymised aggregates.
