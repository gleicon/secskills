Three targets, one workflow

Point it at code, a build, or a live domain. The authorization gate and rate limiting are built into the core.

sourceStatic ast-grep review of a repo. No network, no gate. Findings mapped to OWASP categories and cheat-sheet references.
sandboxBuild and run an artifact isolated in Docker, then probe the running instance.
liveDiscover the attack surface of an authorized domain, then run OWASP-mapped tests.

The engagement

A guided intake makes sure nothing is loose before a single packet is sent.

  1. Intake — research the target (passive OSINT), then a relentless interview on authorization, scope, target class, credentials, and rules of engagement. Writes a locked scope file.
  2. Discover — subfinder → dnsx → httpx with Shodan enrichment, scope-confined.
  3. Test — headers, TLS, unauthenticated exposure, OSV CVEs. --deep adds nuclei, cipher enumeration, content discovery, screenshots.
  4. Report — Markdown, HTML, or a big-4-style PDF with SOC 2 / ISO / PCI mapping and a per-finding owning team.

What's in the box

Safety

Authorization gate

Live and sandbox modes refuse without confirmation or an authorized scope file. Non-destructive by default; intrusive needs a second confirm. No DoS, no unauthorized targets.

Tooling

~63 tools, graceful

The doctor verifies each tool, prints the install command, and catches build collisions. Absent tools are skipped, never fatal.

Knowledge

OWASP, offline

40+ cheat sheets embedded — Web, Mobile, and LLM/Agentic Top 10 — plus per-stack secure/vulnerable recipes.

Findings

Mapped & owned

Every finding carries OWASP, CWE, OSV CVEs, an owning team, and SOC 2 / ISO / PCI controls.

OSINT

Shodan & more

IP space, ASN, open ports, product versions, and SaaS trust surface — throttled to stay under free-source limits.

Hygiene

Token & PII

Compress noisy OSINT, redact PII/secrets before reporting, and flag prompt injection in untrusted target output.

Start in five commands

# install and preflight
make install
secskills doctor

# scope → discover → test → report
secskills profile example.com
secskills scope --init          # edit: authorized, targets, expires
secskills discover example.com
secskills test example.com --deep
secskills report --pdf example.com --output report.pdf
